## 1. දේවල් තිබෙන ස්ථාන

- **Kit.** `packages/ui-kit/src` යනු `packages/ui-kit/UPSTREAM.md` හි සඳහන් commit එකට අදාළ upstream `src/` හි byte-for-byte පිටපතකි (එම ගොනුව license authorization ද සටහන් කරයි); දේශීය patches `PATCHES.md` හි ලැයිස්තුගත කර ඇත (කිසිවක් නැත). එය build කිරීමකින් තොරව source ලෙස භාවිත වේ: `next.config.mjs` එය transpile කරන අතර, `tsconfig.json` මඟින් `@omniroute/ui-kit` → `packages/ui-kit/src` සහ `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` ලෙස map කරයි (`vitest.config.ts` සහ `vitest.mcp.config.ts` ද එම alias එක භාවිත කරයි). Kit component එකක් එහි subpath එකෙන් (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) import කරන්න; කිසි විටෙකත් `@omniroute/ui-kit` barrel එක හරහා නොකරන්න: barrel එක සෑම importer එකකටම සෑම component එකක්ම (date picker එක ඇතුළුව) ඇද ගනී. Kit stylesheet එක `src/app/globals.css` හරහා ඇතුළත් වේ (`@import "../../packages/ui-kit/src/ci-styles.css"`, සම්පූර්ණ sheet එක: core `ci-ui.css` සහ සෑම pattern family එකක්ම).
- **Tokens.** `packages/ui-kit/src/ci-tokens.css` මඟින් `--ci-*` tokens declare කරයි; `src/app/globals.css` ඒවා පැරණි OmniRoute නම් (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`) වෙත bridge කරයි. එම නිසා පවතින `var(--color-*)` reads සහ Tailwind utilities ක්රියාත්මක වේ. නව code එක Tailwind utilities (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) හෝ kit classes භාවිත කරයි — කිසි විටෙකත් hex value එකක් නොවේ (`tests/unit/design-kit-bridge.test.ts` මඟින් bridge එක enforce කරයි). `text-primary` `--text-color-primary` හරහා `--color-primary-ink` වෙත resolve වේ, එබැවින් primary text එක කියවිය හැකිව පවතින අතර `bg-primary`/`border-primary` accent surface එකම තබා ගනී: Editions යටතේ එය kit හි `--ci-color-accent-active` වේ (light හි ගැඹුරු copper `#99562f`, dark හි copper accent); Classic යටතේ light හි lime-800 සහ dark හි lime accent වේ. Chart series `--color-chart-1` … `--color-chart-8` භාවිත කරයි; සෑම එකකටම text-safe `--color-chart-N-ink` සහ opaque `--color-chart-N-subtle` chip tint එකක් ඇත, ඒවා kit series අනුපිළිවෙළට (`ciChartSeriesOrder`) assign කර ඇත.
- **Themes.** `<html className="ci-theme">` (`src/app/layout.tsx`) මඟින් document එක kit theme එකට opt-in කරයි. Preference එක `light`, `dark` හෝ `system` වේ (`src/shared/constants/appConfig.ts` හි `THEME_CONFIG.defaultTheme = "system"`; `system` `prefers-color-scheme` අනුගමනය කරයි). `src/store/themeStore.ts` හි `applyTheme()` (hydration ට පෙර ක්රියාත්මක වන, `src/app/layout.tsx` තුළ inline කර ඇති `THEME_BOOT_SCRIPT` මඟින් mirror කරනු ලබන) `data-theme="dark"|"light"` සකසා `<html>` මත `.dark` class එක එකවර toggle කරයි. Kit හි dark token set එක `data-theme="dark"` මත keyed වේ (`packages/ui-kit/src/ci-tokens.css`); OmniRoute හිම dark overrides (`globals.css` හි `.dark` block එක) සහ පැරණි Tailwind `dark:` utilities `.dark` class එක මත keyed වේ. Accent color presets නොමැත: accent එක සැමවිටම kit එකෙන් පැමිණෙන අතර, පැරණි build එකකින් persisted preset එකක් තිබේ නම් store එක load වන විට එය ඉවත් කරනු ලැබේ.
- **Palettes.** දෙකක් ඇත, දෙකම kit එකෙන් (`src/shared/constants/appearancePalette.ts`): default එක වන `editions` සහ `classic`. Editions යනු `<html>` මත ඇති kit හි `data-ci-appearance="editions"` attribute එකයි; `ci-ui.css` මඟින් import කරන `ci-editions.css` එය `data-theme` සමඟ combine කරයි. Classic යනු එම attribute එක නොමැති වීමයි. Root layout එක attribute එක server-render කරන බැවින්, කිසිවක් stored නොකළ visitor කෙනෙකුට (හෝ JS නොමැති visitor කෙනෙකුට) dashboard, login, `/status`, error pages, `/docs` සහ PWA යන සෑම surface එකකම Editions ලැබේ. තේරීම theme එක සමඟම එකම `theme` store එකෙහි persist කරනු ලැබේ (`src/store/themeStore.ts` හි `palette`, `setPalette()`, `applyPalette()`) සහ `THEME_BOOT_SCRIPT` මඟින් paint ට පෙර apply කරනු ලැබේ (`src/shared/utils/themeBootScript.ts`, layout හි `<head>` තුළ inline කර ඇත). එය attribute එක ඉවත් කරන්නේ stored palette එක `"classic"` වූ විට පමණි; root layout එකෙන් පිටත ඇති `src/app/global-error.tsx` එය එම store එකෙන් apply කරයි. වෙනත් කිසිදු element එකකට `data-ci-appearance` නොදමන්න: kit එක එය `html:root:has([data-ci-appearance="editions"])` සමඟ match කරන බැවින්, එක් descendant එකක් පමණක් වුවද සම්පූර්ණ document එක මාරු කරයි. Editions `data-ci-editions-variant="landing"` variant එක marketing pages සඳහා වන අතර dashboard සඳහා නොවේ.
