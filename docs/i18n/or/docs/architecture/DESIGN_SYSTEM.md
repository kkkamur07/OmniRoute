> **ସ୍ଥିତି:** ଡ୍ୟାସ୍ବୋର୍ଡଟି **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`) ଉପରେ ନିର୍ମିତ, ଯାହାକୁ
> workspace `packages/ui-kit` (`@omniroute/ui-kit`) ଭାବେ vendored କରାଯାଇଛି; upstream snapshot-ଟି
> `packages/ui-kit/UPSTREAM.md`ରେ pin କରାଯାଇଛି ଏବଂ `npm run check:ui-kit-snapshot` ଦ୍ୱାରା ସୁରକ୍ଷିତ। Light ହେଉଛି canonical
> theme; ଡିଫଲ୍ଟ ପସନ୍ଦ ହେଉଛି `system`। ଡିଫଲ୍ଟ palette ହେଉଛି kitର **Editions** appearance
> (ଉଷ୍ମ paper neutrals ଏବଂ copper accent `#e5ac82`, `packages/ui-kit/src/ci-editions.css`); Settings →
> Appearance → Color paletteରେ **Classic** ଉପଲବ୍ଧ, ଯାହା lime accent ସହିତ kitର base tokens ବ୍ୟବହାର କରେ। UI, display ଏବଂ code text ପାଇଁ Switzer
> ହେଉଛି ଏକମାତ୍ର family (`--ci-font-ui`; `--ci-font-display` ଏବଂ
> `--ci-font-mono` ଏହାକୁ resolve କରେ), ଯାହା kit ଦ୍ୱାରା ନିଜେ self-host କରାଯାଇଛି (`packages/ui-kit/src/ci-fonts.css`,
> ଯାହା `ci-tokens.css` ଦ୍ୱାରା import ହୋଇଛି)। Switzerରେ ନଥିବା scriptଗୁଡ଼ିକ glyph ପରେ glyph fallback କରେ (`src/app/globals.css`):
> Cyrillic, Greek ଏବଂ Vietnamese ପାଇଁ Inter, ଏବଂ କେବଳ `html[dir="rtl"]` ଅଧୀନରେ Arabic script ପାଇଁ Vazirmatn।
> ପ୍ରତ୍ୟେକ icon ହେଉଛି ଏକ Lucide glyph।

## 1. ଜିନିଷଗୁଡ଼ିକ କେଉଁଠାରେ ରହେ

- **କିଟ୍।** `packages/ui-kit/src` ହେଉଛି `packages/ui-kit/UPSTREAM.md`ରେ ପିନ୍ କରାଯାଇଥିବା କମିଟ୍ର upstream `src/`ର byte-for-byte କପି (ଏହି ଫାଇଲ୍ରେ ଲାଇସେନ୍ସ ଅନୁମତି ମଧ୍ୟ ରେକର୍ଡ ହୋଇଛି); `PATCHES.md`ରେ ସ୍ଥାନୀୟ patchଗୁଡ଼ିକ ତାଲିକାଭୁକ୍ତ ଅଛି (କିଛି ନାହିଁ)। ଏହାକୁ କୌଣସି build ବିନା source ଭାବେ ବ୍ୟବହାର କରାଯାଏ: `next.config.mjs` ଏହାକୁ transpile କରେ, ଏବଂ `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` ଓ `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` ମ୍ୟାପ୍ କରେ (`vitest.config.ts` ଏବଂ `vitest.mcp.config.ts`ରେ ମଧ୍ୟ ସମାନ alias ଅଛି)। କିଟ୍ componentକୁ ଏହାର subpath (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) ମାଧ୍ୟମରେ import କରନ୍ତୁ, `@omniroute/ui-kit` barrel ମାଧ୍ୟମରେ କେବେ ନୁହେଁ: barrel ପ୍ରତ୍ୟେକ importer ମଧ୍ୟରେ ପ୍ରତ୍ୟେକ component (date picker ସହିତ) ଟାଣି ଆଣେ। କିଟ୍ stylesheet `src/app/globals.css` ମାଧ୍ୟମରେ ଯୋଗ ହୁଏ (`@import "../../packages/ui-kit/src/ci-styles.css"`, ସମ୍ପୂର୍ଣ୍ଣ sheet: core `ci-ui.css` ସହିତ ପ୍ରତ୍ୟେକ pattern family)।

- **ଟୋକେନ୍ଗୁଡ଼ିକ।** `packages/ui-kit/src/ci-tokens.css` `--ci-*` tokenଗୁଡ଼ିକୁ ଘୋଷଣା କରେ; `src/app/globals.css` ସେଗୁଡ଼ିକୁ legacy OmniRoute ନାମଗୁଡ଼ିକ (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`) ସହିତ bridge କରେ, ଯାହାଦ୍ୱାରା ପୂର୍ବରୁ ଥିବା `var(--color-*)` reads ଏବଂ Tailwind utilities କାମ କରି ଚାଲେ। ନୂଆ codeରେ Tailwind utilities (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) କିମ୍ବା kit classes ବ୍ୟବହାର କରନ୍ତୁ — କେବେ ମଧ୍ୟ hex value ନୁହେଁ (`tests/unit/design-kit-bridge.test.ts` bridgeକୁ enforce କରେ)। `text-primary`, `--text-color-primary` ମାଧ୍ୟମରେ `--color-primary-ink`କୁ resolve ହୁଏ, ତେଣୁ primary text ପଢ଼ିବାଯୋଗ୍ୟ ରହେ, ଯେତେବେଳେ `bg-primary`/`border-primary` accent surfaceକୁ ଅବିକୃତ ରଖେ: Editions ଅଧୀନରେ ଏହା kitର `--ci-color-accent-active` (lightରେ ଗାଢ଼ copper `#99562f`, darkରେ copper accent); Classic ଅଧୀନରେ lightରେ lime-800 ଏବଂ darkରେ lime accent। Chart seriesଗୁଡ଼ିକ `--color-chart-1` … `--color-chart-8` ବ୍ୟବହାର କରେ, ପ୍ରତ୍ୟେକରେ text-safe `--color-chart-N-ink` ଏବଂ opaque `--color-chart-N-subtle` chip tint ରହେ, ଯାହା kit series order (`ciChartSeriesOrder`) ଅନୁସାରେ ନିର୍ଦ୍ଧାରିତ।

- **ଥିମ୍ଗୁଡ଼ିକ।** `<html className="ci-theme">` (`src/app/layout.tsx`) documentକୁ kit themeରେ opt in କରେ। ପସନ୍ଦ `light`, `dark` କିମ୍ବା `system` ହୋଇପାରେ (`src/shared/constants/appConfig.ts`ରେ `THEME_CONFIG.defaultTheme = "system"`); `system`, `prefers-color-scheme`କୁ ଅନୁସରଣ କରେ। `src/store/themeStore.ts`ର `applyTheme()` (ହାଇଡ୍ରେସନ୍ ପୂର୍ବରୁ ଚାଲୁଥିବା, `src/app/layout.tsx`ରେ inline ହୋଇଥିବା `THEME_BOOT_SCRIPT` ଦ୍ୱାରା mirror କରାଯାଇଛି) `data-theme="dark"|"light"` ସେଟ୍ କରେ ଏବଂ `<html>`ରେ `.dark` classକୁ ଏକାସାଙ୍ଗରେ toggle କରେ। Kitର dark token set `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`) ଉପରେ ଆଧାରିତ; OmniRouteର ନିଜସ୍ୱ dark overrides (`globals.css`ର `.dark` block) ଏବଂ legacy Tailwind `dark:` utilities `.dark` class ଉପରେ ଆଧାରିତ। କୌଣସି accent color preset ନାହିଁ: accent ସବୁବେଳେ kitରୁ ଆସେ, ଏବଂ ପୁରୁଣା buildରୁ ରହିଯାଇଥିବା preset store load ହେବା ସମୟରେ ବାଦ ଦିଆଯାଏ।

- **ପାଲେଟ୍ଗୁଡ଼ିକ।** ଦୁଇଟି, ଉଭୟ kitରୁ (`src/shared/constants/appearancePalette.ts`): ଡିଫଲ୍ଟ `editions` ଏବଂ `classic`। Editions ହେଉଛି `<html>`ରେ kitର `data-ci-appearance="editions"` attribute, ଯାହାକୁ `ci-ui.css` ଦ୍ୱାରା import ହୋଇଥିବା `ci-editions.css`, `data-theme` ସହିତ ମିଶାଏ; Classic ହେଉଛି attribute ନଥିବା ଅବସ୍ଥା। Root layout server-render କରିବା ସମୟରେ attributeକୁ ସେଟ୍ କରେ, ତେଣୁ କିଛି store ହୋଇନଥିବା visitor (କିମ୍ବା JS ନଥିବା visitor) ପ୍ରତ୍ୟେକ surfaceରେ — dashboard, login, `/status`, error pages, `/docs` ଏବଂ PWAରେ — Editions ପାଏ। ପସନ୍ଦଟି theme ସହିତ ସେହି `theme` storeରେ (`palette`, `setPalette()`, `applyPalette()` `src/store/themeStore.ts`ରେ) persist ହୁଏ ଏବଂ `THEME_BOOT_SCRIPT` ଦ୍ୱାରା paint ପୂର୍ବରୁ ପ୍ରୟୋଗ ହୁଏ (`src/shared/utils/themeBootScript.ts`, layoutର `<head>`ରେ inline ହୋଇଛି); stored palette `"classic"` ହେଲେ ମାତ୍ର ଏହା attributeକୁ remove କରେ। Root layout ବାହାରେ ଥିବା `src/app/global-error.tsx`, ସେହି storeରୁ ଏହାକୁ ପ୍ରୟୋଗ କରେ। ଅନ୍ୟ କୌଣସି elementରେ `data-ci-appearance` ରଖନ୍ତୁ ନାହିଁ: kit ଏହାକୁ `html:root:has([data-ci-appearance="editions"])` ସହିତ match କରେ, ତେଣୁ ଗୋଟିଏ descendant ସମଗ୍ର documentକୁ ବଦଳାଇଦେବ। Editions `data-ci-editions-variant="landing"` variant marketing pages ପାଇଁ, dashboard ପାଇଁ ନୁହେଁ। Browser chrome: server default Editionsକୁ `viewport.themeColor` (ପ୍ରତ୍ୟେକ `prefers-color-scheme` ପାଇଁ ଗୋଟିଏ tag) ଏବଂ web manifestରେ render କରେ — `src/shared/constants/pwaThemeColors.ts`ର `PWA_THEME_COLORS`, Editions `--ci-color-background` (`#f3f1e9` / `#11120f`)ର ଏକମାତ୍ର mirror, `tests/unit/pwa-theme-colors.test.ts` ଦ୍ୱାରା `ci-editions.css`ରେ pinned। ପରେ live `<meta name="theme-color">` stored palette ଏବଂ modeକୁ ଅନୁସରଣ କରେ: `THEME_BOOT_SCRIPT` paint ପୂର୍ବରୁ tagଗୁଡ଼ିକୁ rewrite କରେ ଏବଂ theme storeର actions ପ୍ରତ୍ୟେକ ପରିବର୍ତ୍ତନରେ ଏହା କରେ (`src/shared/utils/themeColorMeta.ts`ରେ `resolveThemeColor()` / `applyThemeColor()`, `ciTokens`ରୁ `CLASSIC_PAGE_BACKGROUND` read କରି)। ଏକ explicit light/dark theme ପ୍ରତ୍ୟେକ tagକୁ ସେହି modeରେ ସେଟ୍ କରେ; `system` ପ୍ରତ୍ୟେକ scheme ପାଇଁ ଗୋଟିଏ colour ରଖେ। Manifest Editionsରେ ହିଁ ରହେ: ଏହା ପ୍ରତ୍ୟେକ install ପାଇଁ ଥରେ fetch ହୁଏ, preference ବିନା। Monaco ଏକ probe (`monacoKitTheme.ts`)ରୁ ଏହାର colours read କରେ; Editions ଅଧୀନରେ probe read ଗୋଟିଏ synchronous pass ପାଇଁ root `data-theme`କୁ flip କରେ, କାରଣ kit rootରୁ Editions light/dark resolve କରେ।

- **Components (adapters)।** `src/shared/components/index.tsx` OmniRoute component APIକୁ ରଖେ (ସମାନ ନାମ, default exports ଏବଂ props), ଏବଂ ଏହା ପଛର primitivesଗୁଡ଼ିକ kit ଉପରେ ନିର୍ମିତ adapters: forms (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlays ଏବଂ feedback (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), structure (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) ଏବଂ tables (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`) ଅଟେ। ଗୋଟିଏ adapter kit componentକୁ subpath ମାଧ୍ୟମରେ import କରେ ଏବଂ legacy propsକୁ ଏହା ଉପରେ map କରେ — ଉଦାହରଣସ୍ୱରୂପ, `Button variant="primary"` kitର `default` button ଅଟେ (`--ci-button-primary-*`: lightରେ inverse surface, darkରେ ଏହାର `--ci-color-accent-foreground` ink ସହିତ accent), `danger` ହେଉଛି `destructive`, ଏବଂ `warning` ହେଉଛି `outline` ସହିତ `.ci-button--warning` extension। `globals.css`ର ଶେଷରେ ଥିବା `.ci-button--warning` ଏବଂ `.ci-badge[data-tone]` rules (`@layer components`) kit classes ଉପରେ ଥିବା OmniRoute extensions। `tests/unit/ui/adapters/*.test.tsx` ପ୍ରତ୍ୟେକ adapterକୁ pin କରେ।
